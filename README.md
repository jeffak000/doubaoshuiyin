# gai溜子 · 豆包去水印工具

> 自学自玩自乐 · 个人项目

一款轻量浏览器用户脚本（Userscript），在 **豆包 AI / DolaAI** 聊天页里，一键下载**无水印**的视频与图片。

![logo](logo.png)

## 功能特性

- **右下角「下载无水印」按钮**：每个视频右下角注入放大版绿色渐变按钮，点一下单独下载当前视频的无水印版，清晰好点。
- **不打扰、不打包**：单条直下，不再弹"一键下载 / 是否打包"的打扰提示。
- **真实无水印源**：通过接口真实地址获取无水印视频源。
- **双站点支持**：doubao.com 与 dola.com 聊天页均可用。
- **全新图标与弹窗**：替换原版头像为专属 logo，弹窗介绍更清爽。

## 安装

1. 安装脚本管理器：**Tampermonkey**（推荐）或 Violentmonkey。
2. 在仓库 Releases 或根目录下载 `doubao-gailiuzi.zip`，解压得到 `doubao-downloader.user.js`。
3. 把 `doubao-downloader.user.js` 拖入脚本管理器，点击安装。
4. 打开豆包聊天页（`doubao.com/chat`）或 DolaAI，生成视频后即可在右下角看到「下载无水印」按钮。

## 使用

1. 在豆包 / Dola 聊天页让 AI 生成视频。
2. 视频右下角出现绿色「下载无水印」按钮。
3. 点击即单独下载该视频的无水印版本。

### 调试（可选）

若按钮未出现或下载异常，打开浏览器控制台执行：

```js
localStorage.setItem('dd-debug', '1')
```

刷新页面后，未匹配到资源的视频会在控制台输出诊断信息，便于排查。
