# gai溜子豆包去水印工具 1.0

> 自学自玩自乐

一款浏览器脚本（Userscript），用于在豆包 AI / DolaAI 聊天页里一键无水印下载生成的视频与图片。

## 功能特性

- 豆包去水印功能开启：安装后页面自动提示功能已启用，不再弹"一键下载 / 是否打包"的打扰提示。
- 右下角「下载无水印」按钮：每个视频右下角注入独立按钮，点一下单独下载当前视频的无水印版。
- 不打扰、不打包：单条直下，不再触发 zip 打包提示。
- 视频去水印：通过接口真实地址获取无水印视频源。
- 支持 doubao.com 与 dola.com 聊天页。

## 安装

1. 给浏览器安装用户脚本管理器：Tampermonkey（推荐）或 Violentmonkey。
2. 下载本仓库的 `doubao-gailiuzi.zip`，解压得到 `doubao-downloader.user.js`。
3. 把 `doubao-downloader.user.js` 拖入脚本管理器页面，点击安装。
4. 打开豆包聊天页（doubao.com/chat）或 DolaAI，生成视频后即可在右下角看到「下载无水印」按钮。

## 使用

1. 在豆包 / Dola 聊天页让 AI 生成视频。
2. 视频右下角出现「下载无水印」按钮。
3. 点击即单独下载该视频的无水印版本。

### 调试（可选）

若按钮未出现或下载异常，打开浏览器控制台执行：

```js
localStorage.setItem('dd-debug', '1')
```

刷新页面后，未匹配到资源的视频会在控制台输出诊断信息，便于排查。
